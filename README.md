# Yuvaraj T · The Data-Verse Portfolio

A futuristic, award-winning portfolio site for **Yuvaraj T — Aspiring Data Analyst & Full Stack Web Developer**.

> Inspired by Spider-Verse aesthetics, cyberpunk UI, Marvel-like cinematic transitions, glassmorphism, neon lighting, comic book effects, and smooth 3D animations. No copyrighted characters, logos, or trademarks are used.

## Run locally

```bash
cd yuvaraj-portfolio
npm install
npm run dev
```

Then open http://localhost:5173

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- **React 18 + Vite + TypeScript**
- **Tailwind CSS** for the design system
- **Framer Motion** for animations
- **Lenis** for smooth scrolling
- **GSAP**-style timing via Framer + CSS keyframes
- Custom canvas-based **particle / node graph** engine (60fps, lightweight — no heavy three.js bundle)
- **Lucide Icons**

## What's inside

- Animated preloader with a spider building a glowing web
- Hero with parallax 3D title, typing role rotation, comic speed-lines, and a superhero silhouette that swings across the screen every 12 seconds
- Background FX: aurora gradients, halftone, grid, rain, lightning, corner webs, floating code snippets & icons, canvas particles with mouse attractor lines
- Custom glowing spider cursor with trail
- Sections: Origin Story, Tech Inventory, Mission Log, Project Vault, Education & Certificates, Leadership, Dashboard Showcase, GitHub graph, Contact
- Sound toggle (synth pad background music), dark/light theme toggle
- Magnetic buttons, ripple click, scroll progress bar, scroll-spy nav
- Confetti on contact form submit, skeleton loaders
- Fully responsive, accessible, lazy-revealed via `whileInView`
